## 简介

权限管理服务接口是基于 RBAC（基于角色的访问控制）模型构建的完整权限管理系统。该系统提供了完整的权限管理功能，包括权限点管理、角色管理、用户角色绑定等核心功能。

RBAC 模型通过三个基本概念实现细粒度的访问控制：
- **用户（User）**：系统的使用者
- **角色（Role）**：一组权限的集合
- **权限（Permission）**：系统中的具体操作能力

该接口设计遵循现代微服务架构原则，采用 gRPC 协议，支持高效的跨服务通信。

## 权限验证机制

### 权限检查流程

```mermaid
flowchart TD
Request[收到请求] --> ParseToken[解析访问令牌]
ParseToken --> ValidateToken{令牌有效?}
ValidateToken --> |否| Reject[拒绝访问]
ValidateToken --> |是| ExtractClaims[提取用户声明]
ExtractClaims --> CheckUserActive{用户状态正常?}
CheckUserActive --> |否| Reject
CheckUserActive --> |是| CheckRoleActive{角色状态正常?}
CheckRoleActive --> |否| Reject
CheckRoleActive --> |是| CheckTimeValid{在有效期内?}
CheckTimeValid --> |否| Reject
CheckTimeValid --> |是| CheckPermissions[检查权限]
CheckPermissions --> CheckDirect{直接权限满足?}
CheckDirect --> |是| Allow[允许访问]
CheckDirect --> |否| CheckTemplate{检查模板权限}
CheckTemplate --> TemplateSatisfied{模板权限满足?}
TemplateSatisfied --> |是| Allow
TemplateSatisfied --> |否| CheckOverride{检查覆盖规则}
CheckOverride --> OverrideSatisfied{覆盖规则满足?}
OverrideSatisfied --> |是| Allow
OverrideSatisfied --> |否| Reject
Allow --> LogAccess[记录访问日志]
Reject --> LogDeny[记录拒绝日志]
LogAccess --> End([完成])
LogDeny --> End
```

## 故障排除指南

### 常见问题及解决方案

#### 1. 权限检查失败
**症状**：用户无法执行预期操作
**排查步骤**：
1. 检查用户是否处于激活状态
2. 验证角色是否在有效期内
3. 确认权限点状态是否启用
4. 检查数据范围限制

#### 2. 角色分配异常
**症状**：用户角色变更不生效
**排查步骤**：
1. 验证角色模板是否正确
2. 检查租户覆盖配置
3. 确认主角色设置
4. 验证时间范围配置

#### 3. 性能问题
**症状**：接口响应缓慢
**排查步骤**：
1. 检查缓存命中率
2. 分析数据库查询计划
3. 监控并发连接数
4. 优化批量操作
